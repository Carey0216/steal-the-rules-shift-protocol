# Changelog

## 1.1.0 — 2026-11-24

- Skip any guide immediately. When more lessons follow, choose Skip current or Skip all this time; cancel resumes the same clip. Skipping onboarding starts gameplay, and skipped campaign mechanics remain replayable.
- Official release with a six-boss Protocol run and a separate 48-sector campaign.
- Three boss phases, two-way rule transfers, hull repair and retries from the current fight.
- Five languages, lessons and drills, keyboard remapping, controller support and accessibility settings.
- Experimental MONEY coin editor, documented in the README.
- Windows x64 and Web HTML5 downloads.
- Smaller browser download, resource verification and a retry button when loading fails.
