# Changelog

## 1.7.0 — 2026-11-23

- Added Protocol run: six bosses in sequence, carried rules, hull repair, retries from the current fight and a final run summary. The 48-sector campaign is still available.
- Bosses change phase at 67% and 34% health. Later phases add return charges, double shockwaves and wider pulse patterns.
- Fixed text wrapping, uneven button sizes, vertical alignment and crowded equipment cards. Guide descriptions scroll at larger text sizes; closing the guide returns to the archive.
- Documented the hidden MONEY coin editor in every README. After the correct command, the game asks for the new amount. Invalid amounts leave the balance unchanged.
- Blocked strikes keep the perfect-dodge counter. Improved damaged-save recovery, remapped scene prompts and Windows virtual keyboard input. Controller A can confirm the next fight.
- Windows x64 and Web HTML5 downloads are included. Existing campaign saves remain compatible.
- Restored the original README header, download badges, detailed guides and centered language navigation.
