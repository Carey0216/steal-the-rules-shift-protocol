# AI use

Carey created this project with substantial AI assistance. Codex helped with design, programming, procedural graphics and audio, translation and documentation. The operative illustration, pose sheet and gate overlook background were generated with OpenAI’s image tool.

The game uses no runtime AI. Native play is offline; the browser version needs only a static host. Progress is stored locally.

Original project files use MIT. Fonts, Godot and its dependencies retain their separate notices. Asset prompts and references are recorded in [ART-NOTES.txt](../assets/ART-NOTES.txt).
