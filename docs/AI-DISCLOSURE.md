# AI use and asset provenance

Created by Carey with substantial AI assistance. Codex assisted with game design, GDScript and C# code, procedural graphics and synthesized audio, testing, balancing, translations, documentation and release preparation. The operative portrait, eight-pose character sheet and gate overlook background were generated with OpenAI's image tool. The backdrop's original generation record and conversion command were recovered from the project's earlier development chat on 2026-11-21; its prompt is recorded in `assets/ART-NOTES.txt`.

No AI runs inside the game. It requires no AI account, API key, external service or network connection during native gameplay. The browser build needs only a static file host. Progress is stored locally.

Code-drawn bosses, arena scenery, equipment symbols and interface shapes are implemented in the source. Sound effects and the backing loop are synthesized in `src/sound.gd`; no downloaded music recordings are used. Fonts have separate SIL Open Font License notices. Godot and its dependencies retain their notices in both release packages.

Original project files use the existing MIT license. AI-assisted assets do not imply exclusive copyright or a guarantee of rights. The referenced interface studies are credited in `assets/ART-NOTES.txt`; their images and code are not distributed.

Suggested jam submission disclosure: “Substantial AI assistance: Codex for design, programming, procedural visuals/audio, testing, translation and documentation; OpenAI image generation for the original operative illustration, animation poses and gate overlook background. No runtime AI.”
