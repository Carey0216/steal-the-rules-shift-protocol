## English

- **Six sectors.** The Lattice collapse opens an upper route and an electrified lower deck. Capacitor, the Furnace and the Mirror add alternating conduits, floor vents and echo strikes. The Executor strengthens the rule you hand it.
- **Campaign map.** Each clear saves locally, lights up the sector and unlocks the next one. Replay cleared sectors and see time, hits and retries. Esc opens Pause with a return-to-lobby button. The Windows gear menu saves and quits.
- **Guided practice.** Five newly recorded lessons show the real inputs and play in order on first launch. Each lesson has a practice arena. Reopen the guide with **?**.
- **Combat and Windows.** Dodge protection lasts 270 ms, with a 150 ms input buffer and a cooldown bar. The HUD previews both sides of a Shift exchange. The Windows launcher pauses the five-Shift shortcut while the game has focus and Sticky Keys is off, then restores it on focus loss or exit.
- Unzip the full Windows archive and double-click `ShiftProtocol.exe`. The Web ZIP includes `index.html` for static hosting. You can use **Q** to exchange rules in either build.

## 日本語

- **6 つの区画。** 第 2 区画の崩落後は高台と通電する下層のルートを使い分けられます。蓄電機、溶鉱炉、反射機にはそれぞれ通電する導管、床の噴出口、直前の位置を狙う攻撃があります。執行機は渡したルールを強化します。
- **区画マップ。** クリアすると端末に保存され、区画が点灯して次が解放されます。クリアした区画に再挑戦し、タイム、被弾、再挑戦回数を確認できます。Esc で一時停止し、ロビーに戻れます。Windows 版は歯車メニューから保存して終了できます。
- **順番に学べるガイド。** 初回起動時に、キー入力を表示した 5 本の新しいプレイ映像を順番に再生します。各レッスンの練習場があり、**？** で見直せます。
- **操作性と Windows。** 回避の保護時間を 270 ms に延長し、150 ms の入力バッファと再使用ゲージを追加しました。交換前に双方が受け取るルールを表示します。固定キーがオフの場合、Windows 版はゲームが前面にある間だけ Shift 5 回のショートカットを停止し、切り替えや終了時に元に戻します。
- Windows 版は ZIP 全体を展開し、`ShiftProtocol.exe` を起動してください。Web 版の ZIP には静的ホスティング用の `index.html` が入っています。どちらも **Q** でルールを交換できます。

- **캠페인 지도.** 구역을 완료하면 기기에 저장되고 해당 구역에 불이 들어오며 다음 구역이 열립니다. 완료한 구역을 다시 플레이하면서 시간, 피격, 재시도 횟수를 확인할 수 있습니다. Esc로 일시 정지한 뒤 로비로 돌아갈 수 있습니다. Windows 톱니바퀴 메뉴에서 저장하고 종료할 수 있습니다.
- **순서대로 보는 조작 가이드.** 첫 실행 때 실제 키 입력이 표시된 새 영상 다섯 편을 순서대로 재생합니다. 각 레슨의 연습장이 있으며 **?**에서 다시 볼 수 있습니다.
- **조작과 Windows.** 회피 보호 시간을 270ms로 늘리고 150ms의 입력 버퍼와 재사용 게이지를 추가했습니다. 교환 전에 양쪽이 얻는 규칙을 보여 줍니다. 고정 키가 꺼져 있을 때 Windows판은 게임이 활성 창인 동안만 Shift 연속 다섯 번 단축키를 끄고, 다른 창으로 전환하거나 종료하면 복원합니다.
- Windows판은 ZIP 전체를 풀고 `ShiftProtocol.exe`를 실행하세요. 웹 ZIP에는 정적 호스팅용 `index.html`이 있습니다. 두 버전 모두 **Q**로 규칙을 교환할 수 있습니다.
