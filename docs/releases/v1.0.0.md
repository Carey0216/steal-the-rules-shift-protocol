## English

- First Game Off build with three bosses: the Warden, the Lattice and the Executor.
- Press **Shift** near an open core to take the boss's rule. Your previous rule goes back to the boss. RUSH, LIFT and AEGIS each change how the fight plays.
- The second arena collapses when you take LIFT. The game includes keyboard and controller controls.
- Windows x64 and Web ZIPs are attached below. These archives were rebuilt from the tagged source.
