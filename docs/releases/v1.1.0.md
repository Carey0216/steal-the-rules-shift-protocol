## English

- Official release: six bosses with three combat phases each, reversible rule transfers, hull repair and retries from the current fight.
- A separate 48-sector campaign across eight regions, with stars, coins, temporary gear and local saves.
- Five languages, gameplay lessons and drills, remappable controls, controller support, assist mode and reduced motion.
- MONEY remains an experimental coin editor. Instructions are in the README; entering the correct command opens the amount prompt.
- Windows x64 and Web HTML5 downloads are included.
- Smaller browser download, resource verification and a retry button if loading fails.
- Skip any guide immediately. When more lessons follow, choose Skip current or Skip all this time; cancel resumes the same clip. Skipping onboarding starts gameplay, and skipped campaign mechanics remain replayable.

## 日本語

- 正式リリース。各3段階の6体のボス、双方向のルール交換、装甲回復、現在のボスからの再挑戦を収録。
- 8地域・48区画の独立した作戦。スター、コイン、時間制の装備とローカル保存に対応。
- 5言語、実機映像の教習と練習、キー設定、コントローラー、アシスト、動きの軽減に対応。
- MONEYは実験的なコイン編集機能です。手順はREADMEに記載。正しいコマンドを入力すると金額入力が開きます。
- Windows x64とWeb HTML5を配布。
- ブラウザー版のダウンロードを軽量化。データの整合性確認と読み込み失敗時の再試行に対応。
- ガイドをすぐにスキップできます。続きがある場合は現在のみ・今回の残りすべてを選択でき、キャンセルすると同じ位置から再開します。初回ガイドのスキップ後はすぐプレイ開始。ガイドはあとから見直せます。

## 한국어

- 정식 출시. 보스마다 세 단계가 있는 여섯 보스, 양방향 규칙 교환, 장갑 회복과 현재 보스부터 재도전을 제공합니다.
- 별도의 8지역 48구역 작전에서 별, 코인, 시간제 장비와 로컬 저장을 지원합니다.
- 5개 언어, 실제 플레이 안내와 연습, 키 설정, 컨트롤러, 보조 모드와 동작 줄이기를 지원합니다.
- MONEY는 실험적 코인 편집 기능으로 유지됩니다. 사용법은 README에 있으며 올바른 명령어를 입력하면 금액 입력이 열립니다.
- Windows x64 및 Web HTML5 다운로드를 제공합니다.
- 브라우저 다운로드 용량을 줄이고 리소스 무결성 확인과 로딩 실패 시 재시도 버튼을 추가했습니다.
- 안내를 바로 건너뛸 수 있습니다. 이어지는 안내가 있으면 현재 안내만 또는 이번 안내 모두를 선택하고, 취소하면 같은 위치에서 계속 봅니다. 첫 안내를 건너뛰면 바로 게임이 시작되며 안내는 나중에 다시 볼 수 있습니다.
