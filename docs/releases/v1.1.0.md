## English

- Official release: six bosses with three combat phases each, reversible rule transfers, hull repair and retries from the current fight.
- A separate 48-sector campaign across eight regions, with stars, coins, temporary gear and local saves.
- Five languages, gameplay lessons and drills, remappable controls, controller support, assist mode and reduced motion.
- MONEY remains an experimental coin editor. Instructions are in the README; entering the correct command opens the amount prompt.
- Windows x64 and Web HTML5 downloads are included.
