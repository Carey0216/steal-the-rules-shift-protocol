# 《STEAL THE RULES: SHIFT PROTOCOL》操作指南

Windows 首次打开游戏时默认全屏。选择 English、中文（简体）、中文（繁體）、日本語或 한국어，按顺序观看五段实战录像。每课均可点击「亲手练习」。结束后进入大厅。

只有一个能力槽。Boss 攻击结束后，核心会打开。靠近出现 **SHIFT** 提示时按 **Shift**，就能把规则抢过来。你的旧规则会交给 Boss，改变它下一次的攻击。夺走 RUSH 会交换双方站位并转向敌人，夺走 LIFT 使 Boss 落地，夺走 AEGIS 会产生短暂破甲增伤窗口。

- **A** 向左，**D** 向右，**空格**跳跃，**J** 挥刀（可按住），**K** 闪避，**Shift** 交换，**E** 用能力。每个动作仅用一个键，可在「设置 → 键盘操作」重设；占用的键会互换，左下角提示会同步更新。
- **RUSH**：沿面向高速斩过目标。**LIFT**：向上喷射，上升时挥刀可以破盾。**AEGIS**：短时间内接下一击，距离 Boss 够近就反弹伤害。
- 看到红色区域就准备躲。冲锋可从上方跳过；空袭先离开落点、再跳过地面冲击波；脉冲柱要从间隙避开。
- 大厅的关卡地图分八区，共 48 关。通关自动存档，点亮本关，并开放下一关。重玩按当次星级发放金币，地图保留该关最高星级。地图右上角的返回箭头可回到大厅。
- 出战前可买至多三种不同装备，每种限一件。点击商城右侧的已购槽位或「撤销」全额退款，即可换购。每颗星 1000 金币，装备 6000 金币起。带减号的气泡暂时削弱属性，只在对抗中掉落。
- 攻击即将命中时闪避穿过，可触发极限闪避。金色环表示反击就绪，2 秒内下一次挥刀命中可额外造成 4 伤害，仅限一次；普通闪避依然提供保护。
- 相位关用 **Shift** 切换 I / II，让对应平台实体化；锚点关先走进范围，再按 **Shift** 交换位置。新机制首次出现前会自动播示范，也有独立练习。
- 13 条路线在检查点后会触发守卫截击，击败守卫才算通关。八个区域最后一关均为 Boss 战。
- 基础五课之后，新玩法会在首次入场前自动播放实机示范。大厅「？」可查看已解锁的示范和装备图鉴。实机录像完整展示战场，自动慢速播放，可暂停、重播。
- [逐关行动表](CAMPAIGN-48-ZH.md)列出了关卡目标、限时气泡和补给规则。
- 进入下一关会继承规则并修复最多三格生命。按 **Esc** 暂停可返回大厅，按 **R** 重开本关。闪避冷却条填满后才能再次闪避。
- 大厅右上角齿轮可调整全屏、语言、字号、辅助模式、键位、总音量、音乐、音效和震屏强度，底部有「保存并退出」。**？** 收录全部 29 段实机示范，随进度解锁。

Windows 解压整包后，双击 `ShiftProtocol.exe`，保留旁边的 `runtime` 文件夹。游戏处于前台时会暂时停用 Windows 的五连 Shift 快捷键，切走或退出时恢复。已启用的粘滞键保持原设置。网页版默认同样使用 **Shift**。
