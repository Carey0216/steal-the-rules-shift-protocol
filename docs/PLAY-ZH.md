# 《STEAL THE RULES: SHIFT PROTOCOL》操作指南

Windows 首次打开游戏时默认全屏。选择 English、中文（简体）、中文（繁體）、日本語或 한국어，按顺序观看五段实战录像。每课均可点击「亲手练习」。结束后进入大厅。

只有一个能力槽。Boss 攻击结束后，核心会打开。靠近到出现 **SHIFT / Q** 提示时按 **Shift**，就能把它的规则抢过来。你原来持有的规则会交给 Boss，决定它接下来怎么攻击。偷完有短暂冷却，可以选择继续挥刀，或者留着现在的规则等下一轮。

- **A / D 或方向键**移动；**空格**跳跃；**J** 挥刀（可按住）；**K** 闪避；**Shift / Q** 交换；**E** 用能力。
- **RUSH**：沿面向高速斩过目标。**LIFT**：向上喷射，上升时挥刀可以破盾。**AEGIS**：短时间内接下一击，距离 Boss 够近就反弹伤害。
- 看到红色区域就准备躲。冲锋可从上方跳过；空袭先离开落点、再跳过地面冲击波；脉冲柱要从间隙避开。
- 大厅的关卡地图共有六关。通关自动存档，点亮本关，并开放下一关。已点亮的关卡可以重玩，重玩不会改掉主线进度。
- 进入下一关会继承规则并修复最多三格生命。按 **Esc** 暂停可返回大厅，按 **R** 重开本关。闪避冷却条填满后才能再次闪避。
- 大厅右上角的齿轮可切换全屏、语言、窗口大小、字号、声音和辅助模式，底部有「保存并退出」。旁边的 **？** 可重看五课。

Windows 解压整包后，双击 `ShiftProtocol.exe`，保留旁边的 `runtime` 文件夹。游戏处于前台时会暂时停用 Windows 的五连 Shift 快捷键，切走或退出时恢复。已启用的粘滞键保持原设置。网页可用 **Q** 交换规则。
