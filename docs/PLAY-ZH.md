# 《STEAL THE RULES: SHIFT PROTOCOL》操作指南

只有一个能力槽。Boss 攻击结束后，核心会打开。靠近到出现 **SHIFT / Q** 提示时按 **Shift**，就能把它的规则抢过来。你原来持有的规则会交给 Boss，决定它接下来怎么攻击。偷完有短暂冷却，可以选择继续挥刀，或者留着现在的规则等下一轮。

- **A / D 或方向键**移动；**空格**跳跃；**J** 挥刀（可按住）；**K** 闪避；**Shift / Q** 交换；**E** 用能力。
- **RUSH**：沿面向高速斩过目标。**LIFT**：向上喷射，上升时挥刀可以破盾。**AEGIS**：短时间内接下一击，距离 Boss 够近就反弹伤害。
- 看到红色区域就准备躲。冲锋可从上方跳过；空袭先离开落点、再跳过地面冲击波；脉冲柱要从间隙避开。
- 下一关会继承规则并修复最多三格生命。失败后按 **Enter** 从该关重来。暂停键为 **Esc**，也可按 **R** 直接重开本关。
- 标题画面按 **H** 开启辅助模式，延长反应窗口。**V** 减少镜头震动与闪光，**M** 静音。

Windows：解压整包，运行 `ShiftProtocol.exe`，保留同目录的 `ShiftProtocol.pck`。网页：在桌面浏览器打开并点击画面聚焦，然后按 Enter。
